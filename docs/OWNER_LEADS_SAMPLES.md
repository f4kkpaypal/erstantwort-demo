# Два настоящих письма собственников

Канал собственников выключен (`OWNER_LEADS_ENABLED=false`), пока нет двух настоящих писем. Формат предположительный, не проверен на реальных письмах. Сейчас парсер понимает только учебную метку `Annahme-Format`. Регистр, лишние пробелы и HTML он уже терпит. Цен и полей Immowelt и Heimziel в коде нет. Продавать «мы отвечаем продавцам с портала» нельзя.

OpenImmo для Immowelt по-прежнему отвечает `NOT_IMPLEMENTED`.

## Какие два образца нужны

1. Одно полное письмо, которое Immowelt (или тот портал, с которого бюро реально получает продавцов) присылает в ящик, когда собственник хочет продать.
2. Второе письмо другого портала, если он есть. Если второго портала нет, хватит двух писем одного портала с разной вёрсткой: одно как обычный текст, одно как HTML.

Нужны не пересказ и не скриншот, а исходное письмо: заголовки и тело, лучше файл `.eml`.

## Как обезличить

Делайте это на своём компьютере. В чат и в git живых людей не кладите.

1. Сохраните письмо как `.eml` из почтовой программы.
2. Замените имя, телефон, почту и улицу на заглушки: `Vorname Nachname`, `+49 000 0000000`, `person@example.invalid`, `Straße 1`.
3. Оставьте как есть: домен отправителя, подписи полей, таблицы, HTML, порядок абзацев, тему письма без фамилии.
4. Проверьте поиск по файлу: старых имени, телефона и улицы больше нет.
5. Положите файл в папку вне репозитория, например `~/erstantwort-samples/`. В git его не добавляйте.
6. Напишите, с какого портала письмо и какой домен отправителя. Домен пойдёт в `OWNER_LEAD_SENDER_DOMAINS`, не в код.

Когда оба образца будут, парсер переписывается под них. Только после этого флаг можно включить. До этого учебные адаптеры остаются, но входящие с этих доменов не читаются.
