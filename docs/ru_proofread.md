# Russian strings for a native read

These lines are author defaults. A native speaker has not signed them off. Roman can mark this file when he has read them.

- Здравствуйте, {имя}, спасибо за интерес к {объект}.
- Здравствуйте, {имя}, спасибо за сообщение по {объект}.
- Цена в объявлении: {цена}.
- Какой день и время вам удобны?
- Брокер подтвердит это лично.
- (Время ещё не зарезервировано.)
- Сообщение подготовлено с помощью ИИ. Напишите STOP, чтобы отписаться.
- Напишите STOP, чтобы отписаться.
- Не понял сообщение, ответьте сами.
- Демо-данные сбрасываются при перезапуске.

The templates live in `core/intl/options.js`.
